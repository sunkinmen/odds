# 賠率獵人 PWA

靜態網站(無後端),把整個資料夾丟到 Cloudflare Pages / GitHub Pages / Netlify 即可,手機開網址後「加入主畫面」。
- `data/matches.json`:由「足球2026_修正版.xlsx」轉出的內建預設資料(6.4 萬場,壓縮後約 650KB,第一次載入後可離線使用)
- 更換資料:設定頁「更換資料」選新的 xlsx/csv(欄位同修正版),存在手機瀏覽器內;「還原內建」可回到預設。`lib/xlsx.mini.min.js` 是解析 xlsx 用的套件
- `engine.js`:四層比對引擎;`parlay.js`:串關推薦;`importer.js`:匯入解析
- `proxy-worker.js`:選用。Cloudflare Worker 轉送,讓「連線抓取」能跨網域(只允許 sportslottery.com.tw)

## 日期
賽事以台灣時間分「今天 / 明天」兩個分頁;沒有日期的匯入場次歸入目前選的那天;已過期的自動移除,後天以後的先略過。串關頁可選今天、明天或今明兩天。

## 取得賽事的方式(由穩到不穩)
1. 手動新增 / 貼上文字(每行 `主隊 客隊 主勝 和 客勝 小分`)
2. 電腦版賠率獵人擴充功能掃描後,複製 JSON,貼到手機 App
3. 網頁書籤(設定頁),在運彩賽事頁按一下複製;若賠率表在跨網域 iframe 內可能抓不到
4. 連線抓取:需自行填入代理網址與運彩 JSON 網址;我無法從開發環境連到運彩網站,**此功能未經實測**

## 注意
隊名需與歷史資料同名(來自運彩),找不到時 App 會提示。最低串數規則請在設定頁自行維護。
